# Third-party assets: Unreal environment slice

Every file below was downloaded from the official Poly Haven file host
(dl.polyhaven.org, resolved through api.polyhaven.com) by
`ThirdParty/fetch_polyhaven.ps1`. None of it is committed; it lives in
`E:\WyndlewoodUnreal\ThirdParty\polyhaven` with a `downloaded.csv` that holds
each file's size and SHA-256.

Licence for every asset: CC0 1.0 Universal (public domain dedication),
https://polyhaven.com/license. Commercial use in a sold game is allowed and
no attribution is required; authors are listed as a courtesy.

## Engine content

The volumetric cloud material and the water plane are Unreal Engine 5.8
built-in content (`/Engine/EngineSky`, `/Engine/BasicShapes`), used under the
owner's Unreal Engine EULA. No Fab or Marketplace content is used.
