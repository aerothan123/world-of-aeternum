# Audio rights replacement: status

Owner decision (asset rights decision 1): every inherited sound marked CC BY-NC, "permission
required" or "with the project only" is replaced in place with original Wyndlewood work, at the
same paths and with the same variant counts, so no code path changes.

## Sound effects (this branch)

526 keys are original paid-plan takes (plan tier: creator, pro, unknown), generated by
`scripts/sfx/rights_replacement_sfx.mjs` from original prompts
(`scripts/sfx/rights_replacement_prompts.mjs`, `scripts/sfx/rights_replacement_prompts_upstream.mjs`).
Each key is one take holding several separate instances, sliced into the key's shipped variant
files and conformed like every generated one-shot; a loop key keeps its seamless take whole. The
raw takes, with each one's date, tier and exact prompt, are in `scripts/sfx/sources/rights/`.

| Group | Keys |
|---|---|
| ambience loops | 11 |
| creature voices | 126 |
| interface | 97 |
| melee and warrior | 93 |
| mounts | 51 |
| movement, combat and player | 33 |
| spells, impacts, projectiles and world | 115 |

Where a take still held fewer separate instances than the key ships, the build repeats one as a
pitch variant (a few percent), so no two files are identical; the build log names those keys.
A replaced key whose gain-map trim sat above the ceiling recomputed from its new takes has that
trim lowered to the ceiling.

## Voices

The voice cast lives on `feature/wyndlewood-voices`: every NPC line is re-voiced from the current
Wyndlewood text by that NPC's own designed voice (ledger:
`docs/audio/elevenlabs_provenance_voices.md`).

## Ledger

Every ElevenLabs file is listed with its date and plan tier in `docs/audio/elevenlabs_provenance.md`
and the `takes.json` beside each set of raw takes. Free-tier output no longer ships.
